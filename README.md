# North Bengal Drive

An open-world 3D driving game inspired by North Bengal and the Eastern Himalayas, playable in the browser.

**Play it: https://debakarr.github.io/north-bengal-drive/**

This repository only serves the built game, on its `gh-pages` branch. The source code is kept in a private repository.
